# Rewrite Checklist

Final QA pass before delivering output — run through this immediately before sending the Optimized Resume + Change Report (`SKILL.md`, Workflow step 7). This is the last safety net against an accidental fabrication or a silently-dropped fact slipping through.

## Factual Integrity

- [ ] Every employer, job title, and date in the output matches the factual audit exactly — none renamed, merged, or reordered without basis.
- [ ] Every metric in the output either came from the source CV or was confirmed by the user during clarification — none invented, rounded up, or estimated.
- [ ] No verb implies a greater scope of ownership than the source supports (no "Led" where the source said "contributed to," no invented headcounts).
- [ ] No skill, tool, or technology appears anywhere in the output (Skills section or prose) that wasn't in the source or confirmed by the user.
- [ ] No certification, award, or degree appears that wasn't in the source.
- [ ] Every claim in the rewritten Summary is traceable to specific content elsewhere in the document.

## Placeholder Integrity

- [ ] Every genuine information gap that wasn't resolved by a clarifying question has a visible `[bracketed placeholder]` in the resume body — none silently smoothed over with vague language instead.
- [ ] Every placeholder in the resume is also listed in the Change Report's "Suggestions Requiring User Input" table.
- [ ] No placeholder was accidentally left in a state that could be mistaken for finished, submit-ready text (check that brackets are intact and the surrounding note about placeholders is present).

## Quality Bar

- [ ] Every rewritten bullet follows [strong verb] + [what was done] + [result if available] + [method if space allows].
- [ ] No bullet uses an unsupported intensifier ("significantly," "dramatically") in place of a real number or concrete outcome.
- [ ] No more than 2-3 bullets share the same opening verb.
- [ ] Tense is consistent within each role and voice is active throughout.
- [ ] No first-person pronouns remain.
- [ ] Section headers are standard and ATS-parseable.
- [ ] Bullet characters, date formats, and spacing are consistent throughout the document.
- [ ] The resume's length matches the target for the candidate's career stage (`references/resume-writing-best-practices.md`) — content was cut rather than length silently allowed to creep, if a conflict arose.

## Reporting Integrity

- [ ] The Change Report's "Remaining Weaknesses" section is honest — it doesn't imply every issue was resolved if placeholders or unaddressed gaps remain.
- [ ] Every keyword listed as "added" in the Change Report is genuinely substantiated in the source, not just present in a target job description.
- [ ] Section-order or section-removal changes are explained, not silent.

If any box on this list doesn't check, fix it before sending — don't deliver output you haven't verified against this list.
