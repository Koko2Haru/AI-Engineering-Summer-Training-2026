# Action Verb Reference

Verb bank for the bullet pass. Organized by accomplishment type so the replacement always matches what actually happened — never swap in a verb that implies a different kind or scope of action than the source describes (see the ownership-level warning in `references/rewriting-guidelines.md`).

## Leadership & Management

Led, Directed, Managed, Oversaw, Coordinated, Orchestrated, Mentored, Championed, Delegated, Supervised, Chaired, Spearheaded, Facilitated, Guided

Use only where the source confirms actual leadership/ownership. If the source says "helped coordinate," a contribution-scoped verb (see Collaboration below) is the honest fit — not "Led."

## Achievement & Results

Achieved, Delivered, Exceeded, Surpassed, Attained, Won, Secured, Generated, Increased, Reduced, Improved, Boosted, Accelerated, Maximized, Minimized

Pair with a real number whenever the source has one; otherwise pair with a concrete, non-numeric outcome ("Delivered the migration ahead of the internal deadline") rather than leaving the verb dangling with no result at all.

## Building & Creating

Built, Designed, Architected, Developed, Engineered, Launched, Created, Established, Founded, Implemented, Constructed, Formulated, Initiated, Pioneered, Prototyped

"Architected" and "Engineered" imply significant technical ownership — reserve for cases where the source supports that scope; "Built" and "Developed" are safer defaults for contributor-level work.

## Technical / Engineering

Automated, Deployed, Migrated, Refactored, Optimized, Debugged, Integrated, Configured, Provisioned, Containerized, Scaled, Instrumented, Benchmarked

## Analysis & Research

Analyzed, Investigated, Evaluated, Diagnosed, Audited, Identified, Modeled, Forecasted, Quantified, Synthesized, Assessed, Validated

## Communication & Collaboration

Presented, Authored, Negotiated, Advised, Consulted, Persuaded, Documented, Trained, Onboarded, Collaborated, Partnered, Liaised, Contributed

Use "Contributed [specific thing]" rather than "Helped with X" for team-effort work — it's stronger than the weak phrasing without overclaiming sole ownership.

## Process Improvement

Streamlined, Standardized, Overhauled, Restructured, Consolidated, Modernized, Simplified, Eliminated

## Financial / Business Impact

Budgeted, Allocated, Reduced (costs), Grew (revenue), Forecasted, Monetized, Negotiated (contracts), Cut (spend)

## Weak Phrases → Rewrite Direction

| Weak Phrase | Rewrite Direction |
|---|---|
| "Responsible for..." | Replace with the action itself: "Managed X," not "Responsible for managing X." |
| "Helped with..." / "Assisted with..." | Name the specific contribution: "Contributed [specific piece]" — keeps honesty about scope while dropping the weak framing. |
| "Worked on..." | Replace with what was actually built/changed, using a verb from the categories above. |
| "Involved in..." | State the specific action taken, if the source specifies one; if it doesn't, this may need a clarifying question about what the actual contribution was. |
| "Duties included..." | Rewrite as a direct achievement bullet, dropping the job-description framing entirely. |
| "Tasked with..." | Focus on what was delivered, not what was assigned. |
| "Participated in..." | Specify the actual contribution if known; ask if not. |

## Weak / Overused Verbs to Replace

Did, Made, Used, Handled, Dealt with, Was in charge of, Got, Gave, Took care of

These describe activity with no signal of skill or scale. Replace with a category-matched verb above once the actual nature of the work is clear from context — if it's genuinely ambiguous what the candidate did, this is a case for a clarifying question rather than a guessed verb.

## Verb Variety Check

If the rewritten resume opens more than 2-3 bullets with the same verb, vary it using a synonym from the same category — don't default back to a weak verb just to avoid repetition, and don't reach for a stronger-category verb than the underlying action supports just for variety's sake.
